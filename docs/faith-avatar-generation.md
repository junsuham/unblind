# 사진 캐릭터 생성 운영

1. 이미지 API 사용이 가능한 OpenAI 프로젝트의 서버 키를 [Vercel 환경 변수](https://vercel.com/unblind/unblind/settings/environment-variables)의 `OPENAI_API_KEY`에 Production 전용으로 등록한 뒤 다시 배포합니다. 키는 Git, 채팅, 브라우저 공개 환경 변수에 넣지 않습니다.
2. 승인된 테스트 계정으로 로그인하고, 홈 → 캐릭터 꾸미기에서 본인이 사용 권한을 가진 테스트 사진 한 장을 선택합니다. 전송 동의 전에는 생성 버튼이 비활성 상태여야 합니다.
3. 동의하고 생성하면 초상에서 도트 스프라이트와 별도의 홈 배경을 만듭니다. 홈을 다시 열고 기도실로 이동해 동일한 캐릭터가 나타나는지 확인합니다. 기도실의 공용 배경은 그대로입니다. 기본으로 돌리면 이 브라우저에 저장된 결과 쌍을 삭제합니다.

원본 사진은 메타데이터를 제거해 OpenAI Images Edits API에 전달하며, 언블라인드 서버에는 원본 또는 결과를 저장하지 않습니다. 생성 결과의 저장 범위는 현재 브라우저의 계정별 저장소입니다. 공급자의 처리·보관은 [OpenAI API 데이터 정책](https://developers.openai.com/api/docs/guides/your-data)을 따릅니다.

생성 한 번당 이미지 편집 호출 두 건이 발생합니다. 요청 한도는 계정당 하루 2회, 서비스 전체 하루 24회 및 분당 2회입니다. 생성 처리 단계에 도달한 시도는 결과가 실패해도 한도를 사용할 수 있습니다. 일별 한도는 한국시간 오전 9시 기준으로 갱신됩니다. API 키가 없으면 메뉴에서는 생성 서비스를 연결할 수 없다는 안내만 보여줍니다.
