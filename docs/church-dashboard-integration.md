# 교회 운영 대시보드 연동

## 현재 연결 대상과 상태

2026-11-25 사용자 요청에 따라 대상은 **연세중앙교회 대학청년회 2부만**으로 정했습니다. 현재 가입 프로필에서 확인된 연세중앙교회 장소 ID는 `way-465724410`이며, 부서는 공란입니다. 관리자 센터에서 실제 2부 소속을 앱 밖에서 확인한 뒤 `2부 · 관리자 소속 확인` 권한을 부여할 수 있습니다. 화면 진입은 관리자 부여 권한과 서버의 교회 ID 일치 검사로 제한되고, 권한 없는 계정에는 진입 버튼도 표시되지 않습니다.

사용자는 기존 자료의 앱 제공 권한과 참여자 동의가 확보됐다고 확인했습니다. 다만 원본 Google Sheets/Calendar의 서버 자격증명이 현재 UNBLIND Vercel 프로젝트에 없고, `church_dashboard_snapshots`에도 대상 자료가 없습니다. 따라서 **현재 배포는 권한형 읽기 화면까지만 연결**되며 실제 수치를 표시하지 않습니다. 2부 원본의 출석·기도·일정 자료 중 공유 승인된 항목만 서버에서 비식별 집계한 뒤, `church_place_id=way-465724410`, `department=2부` 범위로 게시해야 실제 수치가 나타납니다. 원본 개인별 행·기도 내용은 앱으로 복제하지 않습니다.

UNBLIND의 `/church-dashboard`는 공개 대시보드나 Google Sheets를 브라우저에 직접 연결하지 않습니다. 관리자에게 별도로 부여받은 `church_dashboard_access` 권한이 있어야 서버가 자료를 읽습니다. 또한 읽기 경계는 `way-465724410`의 `2부`로 고정되어 있어, 기존 교회 전체 권한이나 다른 부서 권한이 있어도 자료가 열리지 않습니다. 앱 관리자 권한만으로는 열리지 않습니다.

## 배포 전 준비

1. `20261124020000_church_dashboard_access.sql`과 `20261125020000_church_dashboard_verified_2bu.sql` 마이그레이션을 적용합니다.
2. 관리자는 자신의 Google 계정으로 UNBLIND에 로그인하고 대상자의 실제 교회·부서 소속을 앱 밖에서 확인한 뒤 관리자 센터 → 참여자 관리에서 `2부 · 관리자 소속 확인` 범위를 선택합니다. 가입 시 선택한 교회만으로 소속이 증명되지는 않습니다. 공유 관리자 비밀번호/쿠키만으로는 부여·회수할 수 없습니다.
3. 별도 신뢰된 서버 작업이 `church_dashboard_snapshots`에 교회 장소 ID(`church_place_id`)와 부서별 요약을 기록해야 합니다. 빈 부서 문자열은 교회 전체 요약, 특정 부서 문자열은 해당 부서 요약입니다. 앱에서는 이 데이터를 수정할 수 없습니다.

기존 `christ-dashboard` 화면은 현재 실명, 출석, 기도 등 개인별 자료를 포함하므로 iframe이나 공개 URL로 연결하지 않습니다. 원본 데이터의 이용 목적·동의·열람권한을 확인한 뒤 서버에서 비식별 집계만 만들고, `church_place_id`와 부서로 나누어 게시해야 합니다. 이름만으로 교회를 묶으면 동명이교회가 섞일 수 있습니다.

### 기존 `christ-dashboard` 연결 전 확인사항

기존 프로젝트는 특정 행사·부서의 여러 Google Sheets와 Calendar를 서비스 계정으로 읽습니다. 앱 대시보드 열람 권한은 **UNBLIND 이용자에게 화면을 보여줄 권한**일 뿐, 원본 교인 자료를 새 서비스로 이전하거나 다른 이용자에게 제공할 동의를 대신하지 않습니다. UNBLIND 가입 시 받은 교회정보 동의도 가입 확인·운영자 승인 목적이며, 교회별 활동 집계 공유를 포함하지 않습니다.

- 원본 자료의 관리자에게 UNBLIND에서 비식별 운영 요약을 제공할 사용 목적과 열람 대상을 확인합니다.
- 원본 자료에 포함된 사람들의 동의·고지 범위와 필요한 추가 동의를 확인합니다.
- 원본 행이 가리키는 실제 교회 장소 ID와 부서를 확인합니다. 기존 프로젝트의 행사·`2부` 데이터가 모든 교회/부서를 대표한다고 가정하지 않습니다.
- Google 서비스 계정 자격증명은 서버 비밀 환경변수에만 보관하고 브라우저, 공개 링크, iframe, 저장소에 넣지 않습니다.
- 기존 프로젝트에서 원본 행을 서버 안에서 집계한 뒤 아래 허용 필드만 `church_dashboard_snapshots`에 게시합니다. 실제 소속 인원이 5명 미만이거나 기도 기여자가 5명 미만이면 해당 집계를 보내지 않습니다.

위 항목이 확인되기 전에는 권한을 부여받은 계정에도 “연결된 운영 자료가 없습니다”가 표시되는 것이 정상입니다. 실명 자료를 임의로 연결하거나 샘플 수치를 실제 데이터처럼 표시하지 않습니다.

## 게시 가능한 필드

`generated_at`, `member_count`, `attendance_count`, `prayer_contributor_count`, `prayer_minutes`, `care_pending_count`, `upcoming_event_count`, `attendance_weeks`만 사용합니다. `attendance_weeks`는 `[{"date":"YYYY-MM-DD","label":"11월 1주","attendance":12}]` 형태입니다. 기도 시간은 참여자가 5명 이상일 때만 표시됩니다. 교인 실명·교번·이메일·연락처·개별 출석/기도 내용은 이 테이블에 넣지 않습니다.

5명 미만의 교회/부서 수치는 앱 응답에서 모두 가려집니다. 5명 이상인 집계에서도 개별 항목의 1~4건은 가려집니다. 인원 수를 알 수 없는 집계도 가려집니다. 대시보드에는 데이터가 없을 때 임의 수치나 샘플 교인을 표시하지 않습니다.

권한이 회수되거나 이용자의 교회 장소 ID/부서가 바뀌면 다음 페이지·API 요청부터 접근이 거절됩니다. 앱의 `/api/church-dashboard/overview`도 동일한 서버 권한 확인을 거치고 캐시하지 않습니다.
