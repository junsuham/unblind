# 도트 캐릭터와 배경 가져오기

1. 언블라인드 홈에서 **캐릭터 꾸미기 → ChatGPT 열기**를 누릅니다. 새 채팅에서 **임시 채팅**을 직접 켭니다. 메뉴의 **이미지 만들기 요청문**에는 캐릭터용·배경용 예시가 있습니다.
2. 캐릭터는 실제 투명 배경의 PNG 또는 WebP, 배경은 별도의 가로 PNG/JPG/WebP로 저장합니다. 이미지의 원본 파일을 저장하고, 흰색이나 체크무늬가 이미지에 그려진 화면을 캡처하지 마세요. 두 파일 모두 최대 12MB입니다.
3. 언블라인드에서 두 파일을 선택해 **캐릭터와 배경 적용**을 누릅니다. 캐릭터는 홈과 기도실에서 같습니다. 가져온 배경은 홈에만 표시되며 기도실 배경은 기존대로 유지됩니다. 나중에 **기본으로 돌리기**를 누르면 이 기기에 저장한 이미지가 삭제됩니다.

파일 처리와 저장은 브라우저에서만 이루어집니다. 언블라인드의 서버로 파일을 보내거나 ChatGPT에 전송하는 동작이 없고, 이미지 생성 API와 API 키도 필요하지 않습니다. 설치형 웹앱과 Safari 탭의 저장공간은 분리될 수 있으므로, 실제로 사용할 화면에서 가져오세요. 예전에 저장한 캐릭터·배경도 기존 저장공간에서 계속 읽습니다.
